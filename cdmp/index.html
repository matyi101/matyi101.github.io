Study the full question bank with DMBOK references

This static app includes every extracted chapter question and both 100-question practice tests. Each item keeps the source answer key and DMBOK2 page reference, and adds a matched cross-reference to the 2024 revised DMBOK plus a short evidence-based explanation.

Reference note. The question bank was written against DMBOK2 (2017), so the source page number is retained. The revised-edition page is a content match against the supplied 2024 edition. Two apparent page-reference typos in the source bank are flagged inside the relevant explanations.

Choose a section or knowledge area on the left, set a session size, and start. Study mode can show feedback as you go. Exam mode hides answers until submission and uses a 54-second-per-question timer (90 minutes for 100 questions).
