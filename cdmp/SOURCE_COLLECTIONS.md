# Source Collections

The playable 694-question bank is divided into two source collections:

| Collection | Questions | Definition |
|---|---:|---|
| Original | 490 | The initial `CDMP - Data Management Fundamentals Exam Questions` bank. |
| Combined Sources | 204 | All retained, deduplicated, and DMBOK-verified questions imported from the other supplied questionnaires. |

## App behavior

- The **Question source** selector offers `All sources`, `Original`, and `Combined Sources`.
- Question cards display only the collection label, keeping the interface simple.
- The answer explanation retains the precise source name and source question number.
- JSON, CSV, and exported result records contain `source_collection` as well as the detailed provenance fields.
- Question IDs and browser storage keys are unchanged, so existing progress remains compatible.
