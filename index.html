TableReference Structure Rules

SYNTAX BREAKDOWN
<< TABLE_NAME (INSTANCE_ID) . [COLUMNS] [KEY::INDEX] >>
TABLE_NAME: Root folder directory reference
INSTANCE_ID: Identifier suffix (defaults to latest instance)
COLUMNS: Target property field values to extract
KEY::INDEX: Pythonic filter mapping expression
Reduction
<<users>>
One-to-One
<<users[index::self.index]>>
Selection
<<users[name::"alice"]>>
Convolution
users[index::self.index-5:self.index]
